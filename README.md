# 野球用品ECサイト（ポートフォリオ）

## 1. 概要
野球用品をオンラインで購入できるECサイトです。
ユーザーは商品閲覧、カート追加、注文が可能です。

## 2. 想定利用シーン
社内向け業務アプリや小規模ECを想定しています。

## 3. 使用技術
- Python / Django
- HTML / CSS / Bootstrap
- SQLite（学習用）
- GitHub

## 4. 主な機能
- ユーザー登録 / ログイン
- 商品一覧 / 詳細表示
- カート機能
- 注文機能
- 管理者による商品管理

## 5. 画面構成
- トップページ
- 商品一覧
- 商品詳細
- カート
- 注文確認
- 注文完了

## 6. ER図
![ER図](docs/erd.png)

## 7. 技術選定理由
- Django  
  認証機能や管理画面が標準で用意されており、
  ECサイトと相性が良いため。
- RDB  
  注文・商品・ユーザーの関係を
  明確に管理できるため。

## 8. セキュリティ対策
- Django標準の認証・CSRF・XSS対策を利用
- ログインユーザーの権限チェックを実装
- 金額・在庫はサーバー側で再計算

## 9. 起動方法
1. リポジトリをclone
2. 仮想環境を作成
3. 依存関係をインストール
4. サーバー起動
5. http://localhost:8000 にアクセス

## 10. 工夫した点
- 注文と注文明細を分けて管理
- 在庫数を持たせ、注文時にチェック
- 業務アプリを意識した設計
